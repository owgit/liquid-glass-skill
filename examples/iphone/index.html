Buttons and controls

A tinted primary action, a clear secondary one, a switch and a segmented control. The palette and the scrim here change the scene’s own colors and dim attributes.

.primary {
  --glass-tint: rgba(255, 138, 61, .55);
}
.segmented { --glass-frost: .35; }

Tab bar

The bar at the bottom of a mobile page, with a round action beside it. Every tab is a link with a visible label and a 44-pixel target.

.tabs {
  --glass-depth: 1.6;
  --glass-dome: 1.4;
  --glass-tint: rgba(6, 24, 20, .4);
}

A lens you can move

Drag it across the tiles, or focus it and use the arrow keys. A thicker, more domed pane magnifies what is behind it. The lens is shown only while the glass effect is on.

<button glass glass-drag>Drag</button>
.lens {
  --glass-depth: 2;
  --glass-dome: 2.2;
}
